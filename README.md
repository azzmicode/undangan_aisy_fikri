# Undangan Pernikahan Digital: Aisy & Fikri 💍

Website undangan pernikahan digital yang interaktif dan *mobile-friendly*, dirancang dengan elemen visual dinamis dan sistem manajemen tamu (RSVP) terintegrasi.

## 🔗 Live Demo
[Lihat Web Undangan secara langsung](https://azzmicode.github.io/undangan_aisy_fikri/) *(Ubah link ini sesuai URL GitHub Pages lu)*

## ✨ Fitur Utama
* **Desain Mobile-First:** Antarmuka yang dioptimalkan penuh untuk kenyamanan akses melalui *smartphone*.
* **Animasi Interaktif:** Implementasi *library* AOS (Animate On Scroll) untuk memberikan transisi visual yang halus saat menggulir halaman.
* **Background Audio:** Kontrol pemutaran musik latar untuk membangun nuansa dan *user experience* yang lebih mendalam.
* **Sistem RSVP (Buku Tamu):** Integrasi formulir tanpa *backend* menggunakan layanan Formspree untuk pengumpulan data tamu secara *real-time*.
* **Countdown Timer:** Penghitung waktu mundur otomatis menuju hari-H pelaksanaan acara.

## 🛠️ Teknologi yang Digunakan
* HTML5 & CSS3
* Vanilla JavaScript
* AOS (Animate On Scroll) Library
* Formspree (RSVP API)

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repositori ini: 
   `git clone https://github.com/azzmicode/undangan_aisy_fikri.git`
2. Buka folder direktori proyek.
3. Jalankan file `index.html` melalui browser atau menggunakan *Live Server*.
